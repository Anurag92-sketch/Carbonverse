CARBONVERSE — deployment package

1. Upload this folder to a static web host such as GitHub Pages.
2. The site is designed to be public and reusable: it has no login, no per-user database and no built-in expiry.
3. The AI button opens ChatGPT with a pre-written Carbonverse prompt. Each visitor uses their own ChatGPT session/limits.
4. QR codes must point to the final published URL. Because the final URL depends on your hosting account, use qr-generator.html after publishing.
5. Open qr-generator.html, enter your published site URL, and download/print the seven QR codes.

Recommended QR destinations:
#build, #name, #challenge, #isomer, #check, #doubt, #quiz
